# clox

C implementation of The Lox Language, from *Crafting Interpreters* by Robert
Nystrom.

[craftinginterpreters.com](https://craftinginterpreters.com/)


## Build Dependencies

- `git`
- a C11 compiler
- GNU Make.

Build system automatically fetches and installs
[libfun](https://github.com/metwse/libfun.git) and
[rdesc](https://github.com/metwse/rdesc.git).
